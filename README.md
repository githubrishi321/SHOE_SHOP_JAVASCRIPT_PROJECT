# 👟 Shoe Shop Website

A dynamic and interactive **Shoe Shop** website built using **HTML, CSS, and JavaScript**. This project showcases a responsive e-commerce-style frontend with engaging UI components and clean design.

🔗 **Live Demo:** [Click Here to View](https://githubrishi321.github.io/SHOE_SHOP_JAVASCRIPT_PROJECT/)  
📦 **GitHub Repo:** [githubrishi321/SHOE_SHOP_JAVASCRIPT_PROJECT](https://github.com/githubrishi321/SHOE_SHOP_JAVASCRIPT_PROJECT)

---

## 🛍️ Features

- 🖼️ Product cards with images, names, and prices  
- 🛒 Add-to-cart functionality with real-time updates  
- 🔍 Hover effects and interactive elements  
- 💅 Smooth, responsive layout (mobile & desktop friendly)  
- 📱 Built using only **vanilla JavaScript**, **HTML**, and **CSS**

---

## 🛠️ Tech Stack

- ✅ HTML5  
- ✅ CSS3  
- ✅ JavaScript (ES6)
